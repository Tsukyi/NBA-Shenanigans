## nba_api player directory

`data/archive.js` contains player IDs, names, and active flags derived from the nba_api static player directory. Other roster modules use its player ID mappings.

Source: https://github.com/swar/nba_api/blob/master/src/nba_api/stats/library/data.py

Source data updated August 16, 2026; retrieved September 23, 2026.
